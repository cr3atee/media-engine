## Value Objects
Независимые доменные структуры данных.

## ParsedOffer
`ParsedOffer` — единый внутренний формат предложения, полученного из маркетплейса парсером. Он не является моделью БД и не содержит бизнес-решений.

Поля:
- `marketplace`: код маркетплейса, из которого получено предложение.
- `external_id`: внешний идентификатор предложения на стороне источника.
- `title`: исходное название предложения.
- `url`: ссылка на объявление или карточку предложения.
- `price`: цена предложения в `Decimal`.
- `currency`: валюта цены.
- `seller_id`: внешний идентификатор продавца, если источник его предоставляет.
- `seller_name`: отображаемое имя продавца, если источник его предоставляет.
