# Architecture Decisions

## Purpose
Фиксация ключевых архитектурных решений проекта.

## Accepted Decisions
- Каталог построен на атрибутах, а не на дереве.
- Один CatalogItem может иметь множество вариантов.
- Описание продавца не используется для определения товара.
- Используется Decimal для денежных значений.
- При отклонении совпадения администратором эта пара больше автоматически не предлагается.
- Администратор подтверждает решения системы, а не строит каталог вручную.
