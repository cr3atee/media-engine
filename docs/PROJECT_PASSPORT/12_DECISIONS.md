# Architecture Decisions

## Purpose
Фиксация ключевых архитектурных решений проекта.

## Accepted Decisions
- Каталог построен на атрибутах, а не на дереве.
- Один CatalogItem может иметь множество вариантов.
- Описание продавца не используется для определения товара.
- Используется Decimal для денежных значений.
- При отклонении совпадения администратором эта пара больше автоматически не предлагается.
- Администратор подтверждает решения системы, а не строит каталог вручную.

## MVP Decisions (2026-11-24)

- Первая версия остаётся веб-каталогом и сравнением выбранных подписок.
  Локальный агент с импортом cookies площадок, установщик и самостоятельное
  развёртывание для клиентов отложены. Локальный запуск для разработки не
  означает создание отдельного пользовательского приложения.
- Полная анкета условий активации и переписка с каждым продавцом не блокируют
  первую версию. Неизвестные условия допускают помеченное сравнение цен;
  подтверждённые противоречия и разные валюты по-прежнему не смешиваются.
- Пользователь отдельно подтвердил привязку FunPay №19847269 к существующему
  «ExitLag 1 month Key» для первого реального сравнения с GGSEL. Одобрение
  относится только к этой паре и не означает автоматического подтверждения
  других предложений, четвёртого товара или полной эквивалентности условий.
- Пользователь отдельно одобрил FunPay Spotify №79355854 для существующего
  Spotify Premium Individual на месяц. Перед публикацией реальная цена снизилась
  со 164,83 до 164,33 рубля; публикуется новая наблюдаемая цена. Оформление на
  аккаунт с регионом Египет и возможным VPN не выдаётся за безусловный ключ
  или подтверждённую прибыль. Другие предложения автоматически не одобряются.
