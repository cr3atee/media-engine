# Codex Workflow

## Purpose
Правила работы Codex в проекте MediaEngine.

## Rules
- Выполнять только поставленную задачу.
- Не читать лишние файлы.
- Не анализировать весь проект.
- Не менять архитектуру без явного указания.
- Соблюдать полную типизацию.
- После каждой завершённой Feature выполнять commit и push.
- Выводить SHA коммита.

## Scope Control
Любое изменение должно быть ограничено файлами, необходимыми для текущей задачи.

## Commit Discipline
Каждая завершённая Feature должна попадать в отдельный осмысленный commit.
