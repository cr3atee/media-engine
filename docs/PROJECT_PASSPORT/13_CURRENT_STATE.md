# Current State

## Purpose
Краткая фиксация текущего состояния проекта.

## Status
Foundation завершён. Ведётся реализация первого рабочего конвейера получения, нормализации, анализа и подготовки данных к публикации.

## Active Focus
Первый рабочий поток строится вокруг получения предложений маркетплейсов и преобразования их во внутренние доменные форматы.

## Known Gaps
Подробные бизнес-правила, полноценная аналитика, публикация и административные сценарии ещё требуют дальнейшей реализации.

## Architecture Review
Проверены подсистемы parsers, catalog, analytics, services, domain и ai в рамках текущего конвейера обработки изменения цены.

Исправлено: кодовые изменения в рабочем конвейере не потребовались.

Требует внимания позже: RawItem в parser base выглядит legacy-типом рядом с ParsedOffer; CatalogNormalizer зависит от CatalogItem, хотя нормализация работает только со строками; PricePipeline временно использует external_id как title для PriceDropEvent, потому что PriceSnapshot не содержит человекочитаемое название товара.
