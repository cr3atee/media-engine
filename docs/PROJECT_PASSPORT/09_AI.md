# AI

## Purpose

This document records the active AI/content-generation boundary.

## Providers

`AIProvider` is the async provider contract. `FakeAIProvider` supplies local,
deterministic behavior for demos and verification. Durable processing stores only
configured provider/model labels; credentials, prompts, raw responses, and stack
traces are not persisted.

## Prompt Builders

`PriceDropPromptBuilder` converts the temporary price-drop content input into
system and user prompts. Durable market events are adapted explicitly before this
boundary; prompt construction does not own event identity or persistence.

## Durable Processing

`ContentGenerationProcessingService` commits an immutable claimed attempt before
calling `ContentGenerator`. The provider call occurs with no repository scope
open. Success persists text and checksum; transient failure persists a sanitized
error and retry time. Retry creates a new immutable attempt number.

## Restrictions

- No external AI provider is called by Task 6 verification.
- Retry policy belongs to the application service, not provider or repository.
- No provider secret may enter generated-content metadata.
- AI does not run in ingestion, scoring, or database transactions.
